## What is F5 Distributed Cloud?

F5 Distributed Cloud (F5 XC) is a SaaS-based platform for deploying, securing, and operating applications across multi-cloud and edge environments. This documentation hub aggregates all the tools, libraries, and guides built around the F5 XC platform.

## Choosing the Right Tool

### Command-Line Users

If you work in the terminal, start with the [xcsh CLI](https://robinmordasiewicz.github.io/f5xc-xcsh/). It provides full command-line access to F5 Distributed Cloud management operations.

### VS Code Users

The [VS Code Extension](https://robinmordasiewicz.github.io/vscode-f5xc-tools/) lets you manage 236+ F5 XC resource types directly from your editor with tree views, inline editing, and resource creation.

### AI-Assisted Workflows

Two MCP (Model Context Protocol) servers integrate F5 XC with AI coding assistants:

- [API MCP Server](https://robinmordasiewicz.github.io/f5xc-api-mcp/) — exposes 1,500+ API tools for Claude, Copilot, and other AI assistants
- [Cloud Status MCP](https://robinmordasiewicz.github.io/f5xc-cloudstatus-mcp/) — provides real-time F5 Cloud operational status monitoring

The [Plugin Marketplace](https://robinmordasiewicz.github.io/f5xc-marketplace/) offers additional automation plugins for Claude Code.

### Developers

- [Auth Library](https://robinmordasiewicz.github.io/f5xc-auth/) — TypeScript/Node.js library for XDG-compliant credential management
- [API Fixed Specs](https://robinmordasiewicz.github.io/f5xc-api-fixed/) — validated OpenAPI specifications for all F5 XC APIs

### Network Engineers

The [DDoS Administration Guide](https://robinmordasiewicz.github.io/f5xc-ddos-administration-guide/) walks through configuring and managing DDoS protection on F5 Distributed Cloud.

## Documentation Infrastructure

All documentation sites in the F5 XC ecosystem are built with [Astro Starlight](https://starlight.astro.build/) using a shared build system:

- [Docs Builder](https://robinmordasiewicz.github.io/f5xc-docs-builder/) — the containerized build system that turns content repos into documentation sites
- [Docs Theme](https://robinmordasiewicz.github.io/f5xc-docs-theme/) — shared branding, fonts, and styling consumed by all sites at build time
